# Shashwat Jain — Portfolio

A responsive, premium/minimal portfolio built with plain HTML, CSS and JavaScript.

## Files
- index.html — page structure/content
- style.css — theme, responsive layout and animations
- script.js — theme switcher, mobile menu, reveal animations and active navigation

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Customise
1. Replace the SJ monogram with a profile photo later if desired.
2. Replace the `#` LinkedIn/GitHub links in `index.html` with your real profile URLs.
3. Add more internship details when you are ready to publish them.
4. The light/dark theme toggle is already included.
